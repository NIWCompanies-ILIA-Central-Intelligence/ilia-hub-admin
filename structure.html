4 · Living Docs (anti-drift sync)
Because Lane A can't see Lane B's chat, every lane logs to a shared Working Log. That's how the whole system stays in sync.
Working Logs (per lane)Each lane's current state + dated history. Read at start, updated at end of every session.
Active Projects IndexOne page listing every lane and its status.
Daily ReconciliationCentral Command sweeps all logs each day and flags anything out of sync.
